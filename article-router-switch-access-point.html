NETWORK7 นาที

Router, Switch และ Access Point ต่างกันอย่างไร

เข้าใจหน้าที่ของอุปกรณ์เครือข่ายสามชนิด พร้อมโครงสร้างที่เหมาะกับบ้านและสำนักงานขนาดเล็ก

เผยแพร่ 1 ก.ย. 2569·ปรับปรุง 2 ก.ย. 2569
ขอบเขตและข้อควรระวัง

อุปกรณ์หลายรุ่นรวม Router, Switch และ Wi‑Fi ไว้ในกล่องเดียว จึงดูเหมือนเป็นสิ่งเดียวกัน แต่หน้าที่และจุดคอขวดต่างกัน

สรุปก่อนเริ่ม

การเลือกอุปกรณ์ถูกชนิดช่วยแก้ปัญหาได้ตรงจุด เช่น พอร์ตไม่พอควรเพิ่ม Switch ส่วนสัญญาณไม่ครอบคลุมควรเพิ่ม Access Point

1. Router จัดการเส้นทาง

Router เชื่อมเครือข่ายภายในกับอินเทอร์เน็ต ทำ NAT, DHCP, Firewall และ Routing บางรุ่นรองรับ VPN, VLAN และ Multi-WAN ความสามารถ CPU ของ Router มีผลเมื่อเปิด Security หรือ VPN หนัก ๆ

2. Switch เพิ่มการเชื่อมต่อแบบสาย

Switch เชื่อมอุปกรณ์ใน LAN เดียวกัน Managed Switch เพิ่ม VLAN, STP, Link Aggregation และ Monitoring ส่วน PoE Switch จ่ายไฟให้ Access Point, กล้อง หรือโทรศัพท์ IP ได้ผ่านสาย LAN

3. Access Point ให้บริการ Wi‑Fi

Access Point เชื่อมผู้ใช้ไร้สายเข้าสู่ LAN ควรวางตามพื้นที่และความหนาแน่น ไม่ใช่เร่งกำลังส่งสูงสุดเสมอไป ระบบหลาย AP ควรวาง Channel และกำลังส่งให้ Roaming ทำงานเหมาะสม

4. โครงสร้างพื้นฐานที่อ่านง่าย

เส้นทางทั่วไปคือ Internet/ONT → Router/Firewall → Switch → เครื่อง, NAS, กล้อง และ Access Point หากจุดใดเป็น 100 Mbps หรือสายไม่ได้มาตรฐาน จุดนั้นอาจลดความเร็วทั้งเส้นทาง
