DHCP กับ Static IP ใช้ต่างกันอย่างไร?

เข้าใจ DHCP, Static IP และ DHCP Reservation พร้อมแนวทางเลือกใช้และป้องกัน IP Conflict ในบ้านหรือสำนักงาน

เผยแพร่ 1 ก.ย. 2569·ปรับปรุง 2 ก.ย. 2569
ขอบเขตและข้อควรระวัง

ก่อนตั้ง Static IP ต้องทราบ Network, Gateway, DNS และช่วง DHCP ที่ใช้อยู่ การเลือกเลข IP โดยเดาอาจชนกับอุปกรณ์อื่นและทำให้เชื่อมต่อเป็นช่วง ๆ

สรุปก่อนเริ่ม

DHCP เหมาะกับอุปกรณ์ผู้ใช้ที่เข้าออกเครือข่าย ส่วนอุปกรณ์ที่บริการผู้อื่นต้องมีตำแหน่งคงที่ แต่ไม่จำเป็นต้องตั้ง Static ที่ตัวอุปกรณ์ทุกครั้ง

1. DHCP แจกค่าให้อัตโนมัติ

DHCP Server แจก IP Address, Subnet Mask, Gateway, DNS และระยะเวลา Lease ให้ Client ลดงานตั้งค่าทีละเครื่อง เหมาะกับ Notebook, โทรศัพท์ และอุปกรณ์ผู้ใช้ทั่วไป

2. Static IP เหมาะกับบริการคงที่

Server, NAS, Printer, กล้อง หรืออุปกรณ์บริหารเครือข่ายมักต้องใช้ IP เดิมเพื่อให้ระบบอื่นหาเจอ การตั้ง Static ต้องอยู่นอกช่วงที่ DHCP นำไปแจก หรือมีการจัดการไม่ให้ชนกัน

3. DHCP Reservation เป็นทางเลือกที่ดูแลง่าย

Reservation ผูก MAC Address กับ IP ที่ต้องการจาก Router หรือ DHCP Server อุปกรณ์ยังรับค่าอัตโนมัติ แต่ได้เลขเดิม ช่วยดูรายการส่วนกลางและเปลี่ยน Gateway/DNS ได้ง่ายกว่าตั้งค่าทีละเครื่อง

4. ป้องกัน IP Conflict

ทำ IP Plan ระบุช่วง DHCP, Static และ Reserved ตรวจด้วย ipconfig, ARP Table และหน้า Client List ก่อนใช้เลขใหม่ หากพบอาการบางครั้งเข้าได้บางครั้งไม่ได้ ให้ตรวจเลขซ้ำเป็นลำดับแรก ๆ

คำสั่งที่ใช้ตรวจ

ipconfig /all
arp -a

ตั้ง Static IP ที่เครื่องหรือใช้ DHCP Reservation ดีกว่า?

ถ้าควบคุม Router หรือ DHCP Server ได้ Reservation มักดูแลง่ายกว่า เพราะรวมรายการไว้จุดเดียวและลดโอกาสตั้งค่าชนกัน
