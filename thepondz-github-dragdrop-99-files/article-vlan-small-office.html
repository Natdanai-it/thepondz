VLAN สำหรับสำนักงานเล็ก: จำเป็นเมื่อไร

แนวทางแยกเครือข่ายพนักงาน แขก กล้อง และอุปกรณ์ IoT ด้วย VLAN พร้อมข้อควรตรวจเรื่อง Switch, AP และ Firewall

เผยแพร่ 1 ก.ย. 2569·ปรับปรุง 2 ก.ย. 2569
ขอบเขตและข้อควรระวัง

VLAN ไม่ใช่ Security ทั้งหมด ต้องมี Firewall Rule ควบคุมการสื่อสารข้าม VLAN และต้องทำแผน IP, Port และวิธีย้อนกลับก่อนเปลี่ยนระบบจริง

สรุปก่อนเริ่ม

เมื่อทุกอุปกรณ์อยู่เครือข่ายเดียว กล้อง แขก NAS และเครื่องพนักงานมองเห็นกันมากเกินจำเป็น VLAN ช่วยแบ่ง Broadcast Domain และกำหนดสิทธิ์ได้ชัดขึ้น

1. ตัวอย่างการแบ่งเครือข่าย

  • VLAN 10: เครื่องพนักงาน
  • VLAN 20: Server และ NAS
  • VLAN 30: กล้องและ IoT
  • VLAN 40: Guest Wi‑Fi ออกอินเทอร์เน็ตเท่านั้น

2. อุปกรณ์ที่ต้องรองรับ

Router/Firewall ต้องสร้าง Interface และ Rule ข้าม VLAN ได้ Switch ต้องเป็น Managed และ Access Point ต้องผูก SSID กับ VLAN ได้ ตรวจด้วยว่า Uplink ระหว่างอุปกรณ์รองรับ Tagged VLAN

3. ออกแบบ Rule ตามงาน

เริ่มจากปิดข้าม VLAN แล้วเปิดเฉพาะที่จำเป็น เช่น พนักงานเข้าถึง NAS บางพอร์ต ผู้ดูแลเข้าหน้ากล้องได้ แต่ Guest ออกอินเทอร์เน็ตอย่างเดียว ระบุ DNS, DHCP และ NTP ให้ครบ

4. เปลี่ยนทีละส่วนและทดสอบ

สำรอง Configuration จด Port Mapping และทดลองกับอุปกรณ์จำนวนน้อยก่อน ตรวจ DHCP, DNS, Printer, File Share และระบบที่ใช้ Broadcast หากมีปัญหาต้องย้อนกลับได้โดยไม่หยุดงานทั้งหมด
