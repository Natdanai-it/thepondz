คอมช้าต้องเช็กอะไร ก่อนรีเซ็ต Windows

แนวทางแยกสาเหตุคอมช้าจาก CPU, RAM, Disk, Startup, Update และ Hardware โดยไม่รีบลง Windows ใหม่

เผยแพร่ 1 ก.ย. 2569·ปรับปรุง 2 ก.ย. 2569
ขอบเขตและข้อควรระวัง

เริ่มจากวัดอาการและเก็บข้อมูลก่อนแก้ การรีเซ็ต Windows ควรเป็นขั้นท้าย เพราะอาจไม่ช่วยหากต้นเหตุคือ SSD, RAM, ความร้อน หรือโปรแกรมเบื้องหลัง

สรุปก่อนเริ่ม

คำว่า “คอมช้า” อาจหมายถึงเปิดเครื่องช้า เปิดโปรแกรมช้า อินเทอร์เน็ตช้า หรือเครื่องค้างเป็นช่วง ๆ วิธีแก้ที่ดีจึงต้องแยกอาการให้ชัดก่อน

1. เก็บ Baseline ก่อนเปลี่ยนอะไร

จดว่าเริ่มช้าตอนไหน ช้าทุกครั้งหรือเฉพาะช่วง เปิดโปรแกรมอะไรอยู่ และเหลือพื้นที่ไดรฟ์ C เท่าไร จากนั้นเปิด Task Manager ดู CPU, Memory, Disk และ GPU ขณะเกิดอาการ ค่าใดแตะ 90–100% ต่อเนื่องมักเป็นจุดเริ่มต้นของการตรวจ

  • CPU สูง: ดูชื่อ Process และอุณหภูมิ
  • Memory สูง: ดูโปรแกรมที่ใช้ RAM และจำนวนแท็บ
  • Disk 100%: ตรวจชนิดไดรฟ์ สุขภาพ SSD/HDD และงาน Update
  • GPU สูงผิดปกติ: ตรวจโปรแกรมกราฟิก เกม Browser หรือโปรเซสไม่รู้จัก

2. ตัดสาเหตุจากซอฟต์แวร์

ปิดโปรแกรม Startup ที่ไม่จำเป็น ถอนโปรแกรมที่ไม่ได้ใช้ ตรวจ Windows Update และสแกนมัลแวร์ด้วย Windows Security หลีกเลี่ยงโปรแกรมเร่งเครื่องหรือ Registry Cleaner ที่โฆษณาเกินจริง เพราะมักเพิ่มโปรแกรมเบื้องหลังมากกว่าลด

3. ตรวจพื้นที่และสุขภาพอุปกรณ์

ควรเหลือพื้นที่ว่างสำหรับ Update และไฟล์ชั่วคราวอย่างเหมาะสม หากเป็น HDD เก่า การเปลี่ยนเป็น SSD มักเห็นผลกว่าการลง Windows ใหม่ ส่วนเครื่องที่พัดลมดังและช้าหลังใช้งานสักพักควรตรวจอุณหภูมิ ช่องระบายอากาศ และฝุ่น

4. เมื่อไรควรรีเซ็ต Windows

พิจารณารีเซ็ตเมื่อไฟล์ระบบเสีย โปรแกรมชนกันรุนแรง หรือกำจัดมัลแวร์ไม่ได้ และต้องสำรองไฟล์ License, Bookmark, ไฟล์งาน และข้อมูลล็อกอินก่อนเสมอ หากมีเสียงผิดปกติจากไดรฟ์หรือ SMART เตือน ให้สำรองข้อมูลก่อนทดสอบต่อ
