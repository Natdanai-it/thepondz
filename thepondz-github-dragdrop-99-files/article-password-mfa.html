SECURITY7 นาที

ตั้งรหัสผ่านและ MFA ให้ปลอดภัย ใช้งานได้จริง

วางระบบ Passphrase, Password Manager, MFA และ Recovery Code สำหรับบัญชีสำคัญโดยไม่ใช้รหัสซ้ำ

เผยแพร่ 1 ก.ย. 2569·ปรับปรุง 2 ก.ย. 2569
ขอบเขตและข้อควรระวัง

การบังคับเปลี่ยนรหัสบ่อยแต่ใช้รูปแบบเดิม ไม่ช่วยเท่าการใช้รหัสยาวไม่ซ้ำและเปิด MFA การกู้คืนบัญชีต้องถูกป้องกันพอ ๆ กับรหัสหลัก

สรุปก่อนเริ่ม

ความปลอดภัยที่ใช้ยากเกินไปทำให้คนจดรหัสหรือใช้รหัสซ้ำ เป้าหมายคือสร้างระบบที่จำเพียงรหัสหลักที่แข็งแรง แล้วให้เครื่องมือจัดการส่วนที่เหลือ

1. ใช้รหัสยาวและไม่ซ้ำ

ใช้ Passphrase ที่ยาว คาดเดายาก และไม่เกี่ยวกับข้อมูลสาธารณะ แต่ละเว็บไซต์ต้องใช้คนละรหัส เพื่อไม่ให้เหตุรั่วจากบริการหนึ่งลามไปทุกบัญชี

2. ใช้ Password Manager

เลือกผู้ให้บริการที่เชื่อถือได้ ตั้ง Master Password แข็งแรง เปิด MFA และตรวจ Emergency Access/Recovery ให้เข้าใจ Password Manager ช่วยสร้างรหัสสุ่มและเตือนรหัสซ้ำหรือข้อมูลรั่ว

3. เลือก MFA ตามความเสี่ยง

Passkey หรือ Security Key ป้องกัน Phishing ได้ดีกว่า OTP หลายรูปแบบ แอป Authenticator เหมาะกว่ารหัส SMS ในหลายกรณี แต่ควรเก็บ Backup Code แบบออฟไลน์และไม่ถ่ายเก็บรวมกับรหัสผ่าน

4. จัดลำดับบัญชีที่ต้องป้องกันก่อน

เริ่มจากอีเมลหลัก บัญชีธนาคาร Cloud, Social และบัญชีที่ใช้กู้คืนบริการอื่น ตรวจอุปกรณ์และ Session ที่ล็อกอินเป็นระยะ ลบบัญชีหรือ App Permission ที่ไม่ใช้แล้ว
