WEB SYSTEMS9 นาที

อัปเว็บ GitHub Pages ให้ลิงก์และรูปไม่พัง

จัดโครงสร้างไฟล์ ใช้ Relative Path ตรวจตัวพิมพ์เล็กใหญ่ และตั้งค่า Pages ให้เว็บ Static เปิดได้ครบทุกหน้า

เผยแพร่ 1 ก.ย. 2569·ปรับปรุง 2 ก.ย. 2569
ขอบเขตและข้อควรระวัง

GitHub Pages แยกตัวพิมพ์เล็ก–ใหญ่ เช่น Logo.png กับ logo.png เป็นคนละไฟล์ ปัญหาที่เปิดใน Windows ได้แต่ออนไลน์พังมักเกิดจาก Path ไม่ตรง

สรุปก่อนเริ่ม

เว็บ HTML/CSS/JavaScript ธรรมดาสามารถเผยแพร่ด้วย GitHub Pages ได้ฟรี จุดสำคัญคือให้ index.html อยู่ตำแหน่งถูกและทุกไฟล์อ้างอิงแบบเหมาะกับชื่อ Repository

1. โครงสร้างพื้นฐาน

วาง index.html ที่ราก Repository แยก assets/css, assets/js และ assets/img ใช้ชื่อไฟล์ภาษาอังกฤษไม่มีช่องว่างเมื่อทำได้ และไม่อัปไฟล์รหัสผ่านหรือไฟล์ชั่วคราว

2. ใช้ Relative Path

สำหรับเว็บที่อยู่ใต้ /repository-name/ ใช้ assets/img/photo.webp หรือ ../assets/... ตามระดับหน้า หลีกเลี่ยง Path จากเครื่อง เช่น C:\Users\... และ Path ที่ขึ้นต้น /assets หากไม่ได้ตั้ง Base URL

3. เปิด GitHub Pages

ไปที่ Settings → Pages เลือก Branch และโฟลเดอร์ที่ต้องการ รอการ Deploy แล้วตรวจ URL จริง ใช้ DevTools ดู 404, Mixed Content และ JavaScript error

4. Checklist ก่อนส่งลิงก์

ทดสอบหน้าแรก หน้าย่อย รูป เมนู Mobile, 404, Canonical, Sitemap และ Form/ลิงก์ภายนอก ลองเปิดแบบ Incognito เพื่อไม่ให้ Cache หรือ Session เดิมทำให้เข้าใจผิด

คำสั่งที่ใช้ตรวจ

git add .
git commit -m "Update website"
