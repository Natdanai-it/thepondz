IT PROCUREMENT10 นาที

อ่านสเปกและใบเสนอราคา IT อย่างไรไม่ให้เทียบผิด

เริ่มจาก Requirement แล้วแยก Must, Should, Optional ก่อนเทียบ CPU, RAM, Storage, Network, Warranty และ License

เผยแพร่ 1 ก.ย. 2569·ปรับปรุง 2 ก.ย. 2569
ขอบเขตและข้อควรระวัง

ชื่อรุ่นหรือคำว่า “เทียบเท่า” อย่างเดียวไม่พอ ต้องตรวจ Generation, Feature, Interface, License, Warranty และเงื่อนไขใช้งานร่วมกัน

สรุปก่อนเริ่ม

การเทียบสเปกที่ดีไม่ใช่เลือกตัวเลขสูงสุด แต่เลือกสินค้าที่ตอบโจทย์งาน เข้ากับระบบเดิม และมีต้นทุนตลอดอายุใช้งานเหมาะสม

1. แปลงความต้องการเป็นเกณฑ์

แยกเป็น Must ขาดไม่ได้, Should ควรมี และ Optional เป็นส่วนเพิ่ม ระบุจำนวนผู้ใช้ โปรแกรม ขนาดข้อมูล ระยะเวลาใช้งาน และข้อจำกัดของระบบเดิมก่อนเปิดดูรุ่นสินค้า

2. เทียบ Hardware บนฐานเดียวกัน

  • CPU: รุ่น, Generation, Core/Thread และข้อจำกัดพลังงาน
  • RAM: ความจุ ชนิด ความเร็ว จำนวนสล็อต และขยายได้สูงสุด
  • Storage: ประเภท Interface, Endurance, RAID และจำนวน Bay
  • Network: ความเร็ว Port, PoE, Wi‑Fi Standard และ License

3. อย่าลืม Software และเงื่อนไข

ตรวจ Edition, User/Device License, Subscription, CAL, Support, Warranty On-site และสิทธิ์อัปเกรด ข้อเสนอที่ราคาต่ำอาจไม่รวม License, Rail kit, Transceiver หรือบริการติดตั้ง

4. สรุปเป็น Comparison Matrix

วาง Requirement ไว้แถวแรก แล้วให้แต่ละรุ่นตอบ Pass, Partial หรือ Fail พร้อมลิงก์ Datasheet และหมายเหตุ หลีกเลี่ยงการคัดข้อความการตลาดโดยไม่มีเอกสารยืนยัน
