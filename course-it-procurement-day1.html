MODULE 01 · TOPIC 01–02

พื้นฐานระบบ IT & การทำงานของ Computer

2 หัวข้อ
01

ภาพรวมระบบ IT

ระบบ IT ในองค์กรประกอบด้วย 4 ส่วนหลัก

Hardware

อุปกรณ์ที่สามารถจับต้องได้ เช่น

  • Notebook
  • Desktop Computer
  • Workstation
  • Server
  • Monitor
  • CPU
  • GPU
  • RAM
  • HDD / SSD
  • Router
  • Switch
  • Firewall
  • Access Point

ตัวอย่าง

บริษัทซื้อ Notebook 20 เครื่องให้พนักงานบัญชี

Notebook ทั้ง 20 เครื่องถือเป็น Hardware

Software

โปรแกรมหรือระบบที่ทำงานอยู่บน Hardware เช่น

  • Windows
  • Microsoft Office
  • Microsoft 365
  • Adobe Photoshop
  • AutoCAD
  • Antivirus
  • ERP
  • โปรแกรมบัญชี

ตัวอย่าง

Notebook เป็น Hardware

Windows 11 เป็น Operating System

Microsoft Excel เป็น Software

ทั้ง 3 อย่างเป็นคนละส่วนกัน

License

License คือ สิทธิ์ในการใช้ Software หรือ Service

การมีไฟล์ติดตั้ง Software ไม่ได้หมายความว่าเรามีสิทธิ์ใช้งานอย่างถูกต้องเสมอไป

ตัวอย่าง

Microsoft 365 Business Standard

50 Users

1 Year

หมายความว่าองค์กรซื้อสิทธิ์ Microsoft 365 สำหรับผู้ใช้งาน 50 คน เป็นระยะเวลา 1 ปี

Service

บริการ IT ที่บริษัทซื้อโดยอาจไม่มีอุปกรณ์ส่งมาให้จับต้อง เช่น

  • Cloud
  • Backup Service
  • Email Service
  • Hosting
  • Support
  • Maintenance
  • Installation
  • Configuration
  • Managed Service

ตัวอย่าง

บริษัทจ่าย Microsoft Azure เดือนละ 20,000 บาท

บริษัทไม่ได้ซื้อ Server กลับมาไว้ที่บริษัท แต่เช่าทรัพยากร Server บน Cloud

02

Computer ทำงานอย่างไร

Computer หนึ่งเครื่องไม่ได้มีแค่ CPU

องค์ประกอบหลักได้แก่

CPU

ประมวลผลคำสั่ง

RAM

เก็บข้อมูลชั่วคราวที่กำลังใช้งาน

Storage

เก็บข้อมูลระยะยาว

GPU

ประมวลผลภาพ กราฟิก และงานเฉพาะทาง

Operating System

ควบคุม Hardware และเป็นพื้นฐานให้ Software ทำงาน

Software

โปรแกรมที่ผู้ใช้ต้องการใช้งาน

ตัวอย่างเปรียบเทียบกับโต๊ะทำงาน

ให้คิดว่าคอมพิวเตอร์เป็นสำนักงานหนึ่งโต๊ะ

CPU = พนักงาน

เป็นคนที่ทำงานและคำนวณข้อมูล

พนักงานทำงานเร็ว งานก็เสร็จเร็วขึ้น

RAM = โต๊ะทำงาน

โต๊ะยิ่งใหญ่ ยิ่งสามารถวางเอกสารหลายชุดเพื่อทำงานพร้อมกันได้

ถ้าโต๊ะเล็กมาก ต้องคอยเก็บเอกสารเข้าออกตลอด ทำให้งานช้าลง

Storage = ตู้เก็บเอกสาร

ใช้เก็บข้อมูลที่ยังต้องอยู่แม้ปิดเครื่องแล้ว

เช่น

  • Word
  • Excel
  • รูปภาพ
  • Video
  • Database

GPU = ผู้เชี่ยวชาญด้านงานภาพ

ถ้ามีงานเอกสารทั่วไป อาจไม่จำเป็นต้องมีผู้เชี่ยวชาญ

แต่ถ้าเป็น

  • 3D
  • Video
  • AI
  • CAD

การมี GPU ที่เหมาะสมจะช่วยงานได้มาก

07

Core คืออะไร

CPU ปัจจุบันมีหน่วยประมวลผลหลายหน่วยอยู่ภายใน CPU ตัวเดียว

เรียกว่า

Core

ตัวอย่าง

  • 4 Core
  • 6 Core
  • 8 Core
  • 16 Core
  • 32 Core

Core มากช่วยอะไร

งานบางประเภทสามารถแบ่งงานออกเป็นหลายส่วนแล้วให้หลาย Core ทำพร้อมกันได้

ตัวอย่าง

CPU 8 Core

เปรียบเหมือนมีพนักงาน 8 คนช่วยกันทำงาน

แทนที่จะมีเพียงคนเดียว

เหมาะกับงาน เช่น

  • Rendering
  • Video
  • Virtual Machine
  • Data Processing
  • Server

แต่ Core มากกว่าไม่ได้แปลว่าเร็วกว่าเสมอ เพราะประสิทธิภาพของแต่ละ Core ก็ต่างกัน

08

Thread คืออะไร

Thread คือจำนวนชุดคำสั่งที่ CPU สามารถจัดการพร้อมกันในเชิง Logical

ตัวอย่าง

8 Core / 16 Threads

หมายความว่า CPU มี 8 Core และสามารถจัดการชุดงานได้สูงสุด 16 Logical Threads ตามสถาปัตยกรรมของ CPU นั้น

สำหรับงานจัดซื้อ ไม่จำเป็นต้องลงลึกถึงวิธีทำงานภายใน

ให้เข้าใจเพียงว่า

งานหลายอย่างพร้อมกัน มักได้ประโยชน์จากจำนวน Core / Thread ที่มากขึ้น

09

Clock Speed คืออะไร

Clock Speed วัดเป็น GHz

ตัวอย่าง

  • 2.4 GHz
  • 3.5 GHz
  • 5.0 GHz

เป็นค่าที่เกี่ยวข้องกับความถี่ในการทำงานของ CPU

แต่ไม่ควรใช้ GHz เพียงอย่างเดียวในการตัดสิน Performance

ตัวอย่าง

CPU A

รุ่นเก่า 5.0 GHz

CPU B

รุ่นใหม่ 4.5 GHz

CPU B อาจเร็วกว่าได้ เพราะโครงสร้าง CPU มีประสิทธิภาพสูงกว่า

ดังนั้น

GHz สูงกว่า ≠ CPU ดีกว่าเสมอ

10

ตัวอักษรท้าย CPU

CPU Notebook มักมีตัวอักษรท้าย Model

เช่น

  • U
  • H
  • HX

โดยทั่วไปใช้บอกกลุ่มการออกแบบของ CPU

U

มักเน้นประหยัดพลังงาน

เหมาะกับ Notebook ที่ต้องการ Battery และการพกพา

H

เน้นประสิทธิภาพมากขึ้น

มักพบใน Notebook สำหรับ

  • งานหนัก
  • Gaming
  • Content Creation

HX

เน้น Performance สูงมากใน Notebook ระดับสูงบางกลุ่ม

ตัวอย่าง

Notebook 2 เครื่องใช้คำว่า

Core Ultra 7

เหมือนกัน

แต่เครื่องหนึ่งเป็น CPU กลุ่มประหยัดไฟ

อีกเครื่องเป็น CPU กลุ่ม Performance

จึงอาจให้ประสิทธิภาพต่างกันมาก

VRAM คืออะไร

  • 6GB
  • 8GB
  • 12GB
  • 16GB
  • 24GB

แต่

VRAM มากกว่า ≠ GPU เร็วกว่าเสมอ

ยังต้องดู GPU Model และ Architecture

16

GPU สำหรับ AI

RAM คืออะไร

RAM ย่อมาจาก

Random Access Memory

เป็นหน่วยความจำที่ Computer ใช้เก็บข้อมูลที่กำลังทำงานอยู่

เมื่อปิดเครื่อง ข้อมูลใน RAM จะหายไป

  • Outlook
  • Teams
  • ERP

ถ้า RAM ไม่เพียงพอ

เครื่องจะเริ่มช้าและต้องใช้ Storage ช่วย

64GB+

19

DDR4 และ DDR5

DDR คือมาตรฐานของ RAM

รุ่นที่พบทั่วไป เช่น

  • DDR4
  • DDR5

DDR5 เป็น Generation ใหม่กว่า

แต่ไม่ได้หมายความว่าสามารถใส่แทน DDR4 ได้ทันที

ตัวอย่าง Compatibility

Notebook A

รองรับ DDR4

RAM ที่ต้องการซื้อ

DDR5

นี่คือตัวอย่างของ

Better Specification ≠ Compatible

20

RAM แบบ ECC

ECC ย่อมาจาก

Error Correcting Code

สามารถตรวจและแก้ Memory Error บางประเภทได้

นิยมใช้ใน

  • Server
  • Workstation
  • ระบบสำคัญ

เพราะระบบเหล่านี้ต้องการ Reliability สูง

ตัวอย่าง

Server เดิมใช้

ECC RAM

Vendor เสนอ RAM Desktop ปกติ

แม้

  • Capacity เท่ากัน
  • DDR เท่ากัน
  • Speed ใกล้กัน

ก็อาจใช้แทนไม่ได้

21

RAM ต้องดูมากกว่าความจุ

Requirement

RAM 32GB

อาจยังไม่พอ

อาจต้องรู้

  • DDR4 หรือ DDR5
  • ECC หรือ Non-ECC
  • Speed
  • Form Factor
  • จำนวน Module
  • จำนวน Slot
  • Compatibility

ในขณะที่ Option A อาจได้ประโยชน์จาก Memory Configuration บางแบบ

HDD คืออะไร

HDD ย่อมาจาก

Hard Disk Drive

ใช้จานแม่เหล็กหมุนเพื่อจัดเก็บข้อมูล

SSD คืออะไร

SSD ย่อมาจาก

Solid State Drive
