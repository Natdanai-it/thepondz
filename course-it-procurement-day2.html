  • ใช้ Internet
  • แชร์ไฟล์
  • ใช้ Printer
  • เข้าถึง Server
  • ใช้งาน Application
  • ใช้ระบบ Cloud

ตัวอย่างอุปกรณ์ใน Network

  • Notebook
  • Desktop
  • Server
  • Printer
  • IP Camera
  • Access Point
  • Switch
  • Router
  • Firewall
02

  • Access Point 5 ตัว
  • IP Camera 20 ตัว
  • Server 2 เครื่อง

สรุป Server

Server ไม่ใช่ Computer ที่มี Spec สูงเท่านั้น

แต่ต้องดู

  • Reliability
  • Redundancy
  • Compatibility
  • Manageability
  • Support

และส่วนประกอบต่าง ๆ ต้องทำงานร่วมกัน

101

สรุป VM

Virtual Machine คือการนำ Physical Hardware

มาแบ่งเป็น Server เสมือนหลายตัว

ทำให้ใช้ Resource ได้คุ้มขึ้น

แต่ VM ยังต้องพึ่ง

  • Physical Server
  • Storage
  • Network
  • Backup
102

สรุป Cloud

Cloud คือการเช่า IT Resource จาก Provider

ข้อดีคือ

  • Flexible
  • Scale ได้ง่าย
  • Deploy เร็ว

แต่ Procurement ต้องดู

  • Recurring Cost
  • Billing Model
  • License
  • Backup
  • Traffic
  • Support

สิ่งที่ต้องจำจาก Day 2

1.

24 Port Switch เหมือนกัน ไม่ได้แปลว่า Spec เหมือนกัน

2.

3.

4.

5.

7.

Hardware + License + Support ต้องตรวจแยกจากกัน

ก่อนเข้าสู่ Day 3

เมื่อจบ Day 2 ผู้เรียนควรสามารถเห็น Requirement เช่น

24-Port Managed PoE+ Switch 4 × 10G SFP+ PoE Budget 370W VLAN Support 3-Year Warranty

หรือ

FortiGate Firewall IPS ≥ 1Gbps Security Subscription 3 Years

หรือ

Rack Server 256GB ECC RAM RAID 10 Dual PSU

แล้วอย่างน้อยสามารถแยกได้ว่า

  • แต่ละคำหมายถึงอะไร
  • รายการใดเป็น Requirement สำคัญ
  • ตัวเลขใดไม่ควรนำมาเทียบตรง ๆ
  • มี License หรือ Service อะไรเกี่ยวข้อง
  • ข้อมูลใดยังไม่เพียงพอ
  • มีอะไรที่ต้องถามฝ่าย IT เพิ่ม

Day 3 จึงจะนำความรู้ทั้งหมดมาใช้กับโจทย์หลักของงานจัดซื้อ คือ

“ถ้าของเดิมหาไม่ได้ จะหารุ่นไหนมาใช้แทน และพิสูจน์อย่างไรว่าทดแทนได้?”
