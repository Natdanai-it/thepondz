0x80070035 และ Network Path ควรไล่ตรวจอะไรบ้าง?

วิธีตรวจปัญหา Network Path และ File Sharing บน Windows จากการเชื่อมต่อ IP DNS ไปจนถึง Permission

ขอบเขต: เหมาะกับ Windows ในบ้านหรือสำนักงานทั่วไป หากเป็นระบบองค์กรหรือ Domain ควรแจ้งผู้ดูแลก่อนเปลี่ยน Policy

1. แยกก่อนว่า Network เสียหรือ Share เสีย

ลองเปิดเว็บไซต์และ Ping Default Gateway หากอินเทอร์เน็ตและ Gateway ใช้ได้ แต่เปิด Shared Folder ไม่ได้ ปัญหามักอยู่ที่ชื่อเครื่อง เส้นทาง Share, Firewall, Service หรือ Permission

2. ทดสอบด้วย IP และชื่อเครื่อง

  1. ใช้ ipconfig ดู IPv4 และ Default Gateway
  2. ลอง ping IP-ปลายทาง
  3. เปิด \\IP-ปลายทาง\ชื่อแชร์
  4. เปรียบเทียบกับ \\ชื่อเครื่อง\ชื่อแชร์

หากเปิดด้วย IP ได้แต่ชื่อเครื่องไม่ได้ ให้ตรวจ DNS, NetBIOS หรือ Name Resolution ก่อนแก้ Permission

3. ตรวจ File Sharing

  • Network Profile ควรเป็น Private ในเครือข่ายที่เชื่อถือได้
  • เปิด Network Discovery และ File and Printer Sharing
  • ตรวจว่า Folder ถูก Share และบัญชีผู้ใช้มีทั้ง Share Permission และ NTFS Permission
  • ตรวจ Firewall Rule โดยไม่ปิด Firewall ทั้งระบบ

4. สิ่งที่ไม่ควรทำทันที

อย่าเปิด SMB1, ปิด Firewall หรือให้ Everyone Full Control โดยไม่ทราบสาเหตุ เพราะเพิ่มความเสี่ยงและทำให้หาต้นเหตุจริงยากขึ้น
