รุ่น 2026-10-11-R2 — คอร์สสร้างเว็บสื่อเด็กจนเปิดขาย

วิธีเปิดไฟล์
1. แตก ZIP ทั้งชุดลงโฟลเดอร์ใหม่ ไม่เปิด HTML จากในหน้าต่าง ZIP
2. เปิด 00-START-HERE.html แล้วกดเริ่มขั้น 1
3. หน้า index.html เป็นเว็บไซต์เดิม มีแบนเนอร์คอร์สใหม่ด้านบน
4. ถ้าลงโฮสต์ ให้อัปโหลดไฟล์ทั้งหมดรวม assets โดยคงตำแหน่งเดิม

ตรวจว่าเป็นรุ่นนี้: หน้าคอร์สแสดง 2026-10-11-R2 และมี 10 ขั้น

1. กำหนดสิ่งที่จะขาย
2. เลือกบริการและวางงบ
3. เตรียมบัญชีและเครื่องมือ
4. สร้างและลองหน้าเว็บ
5. สร้างฐานข้อมูลและกฎสิทธิ์
6. เชื่อมสมาชิกและหน้าเจ้าของ
7. นำสื่อเข้าระบบ
8. ทดสอบและนำเว็บขึ้นออนไลน์
9. เชื่อมชื่อเว็บและตรวจของจริง
10. เปิดขายและดูแลต่อ
