PRIVATE COURSE ACCESS

เรียนจบแล้ว ยังกลับมาดูและอ่านย้อนหลังได้

สิทธิ์แยกตามลูกค้าและคอร์ส ไม่ใช้ลิงก์รวมสาธารณะ

AFTER-CLASS PRIVATE LIBRARY

หลังเรียนมี วิดีโอและสไลด์ย้อนหลัง

ลูกค้าแต่ละคนได้รับพื้นที่ Private แยกตามคอร์สและแพ็กเกจ เพื่อกลับมาดูวิดีโอ อ่านสไลด์ และใช้ไฟล์ Workshop ของตนเอง

01 · VIDEO REPLAY

วิดีโอแยกตามวันเรียน

ย้อนดูขั้นตอนหรือบทที่ต้องการได้ โดยมีการบันทึกเมื่อผู้เรียนและผู้เข้าร่วมยินยอม

02 · SLIDES & READING

สไลด์ คู่มือ และ Checklist

เอกสารที่ใช้สอนจริง พร้อมเนื้อหาอ่านต่อที่เหมาะกับพื้นฐานและเป้าหมายของลูกค้า

03 · PRIVATE FILES

Workshop และ Project Files

ไฟล์ฝึก Template หรือ Source Code ถูกแยกตามผู้เรียน ไม่ใช้ลิงก์รวมสาธารณะ

Private by course: คอร์สหลักเปิดดูเนื้อหาฉบับเต็มได้ทันทีที่กดเข้าคอร์ส โดยต้องกรอกรหัสผ่านสำหรับลูกค้าก่อน ส่วนวิดีโอ เฉลย และไฟล์ Workshop เปิดผ่านลิงก์ส่วนตัวตามระยะเวลาที่ตกลง

ACCESS FLOW

ขั้นตอนรับ สิทธิ์หลังเรียน

01

ยืนยัน Scope

ตกลงคอร์ส การบันทึก รายการไฟล์ และระยะเวลาเข้าถึงก่อนเริ่มเรียน

02

รับลิงก์และรหัสคอร์ส

ลูกค้าได้รับรหัสสำหรับเปิดบทเรียนฉบับเต็ม พร้อมลิงก์วิดีโอและไฟล์ตามแพ็กเกจ

03

เรียนและทบทวนตามสิทธิ์

เปิดเนื้อหาคอร์สเพื่อใช้สอน ดูวิดีโอ อ่านสไลด์ และดาวน์โหลดไฟล์ฝึกตามแพ็กเกจ

ACCESS SECURITY

แยกให้ชัดระหว่าง ระบบปัจจุบันและระบบบัญชี

ปัจจุบันใช้ไฟล์บทเรียนเข้ารหัสและรหัสกลุ่มแยกตามคอร์ส โดยไม่เก็บรหัสไว้ใน GitHub เหมาะกับลูกค้าจำนวนน้อย
