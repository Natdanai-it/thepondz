NETWORK8 นาที

Wi-Fi ช้าหรืออินเทอร์เน็ตช้า แยกอย่างไร

ทดสอบจาก Gateway, สาย LAN, Speed Test และตำแหน่งใช้งาน เพื่อแยกปัญหา Wi‑Fi ภายในออกจากผู้ให้บริการอินเทอร์เน็ต

เผยแพร่ 1 ก.ย. 2569·ปรับปรุง 2 ก.ย. 2569
ขอบเขตและข้อควรระวัง

อย่าเปลี่ยน Router ทันทีโดยยังไม่ทดสอบผ่านสาย LAN เพราะปัญหาอาจมาจากสัญญาณ Wi‑Fi, สาย, ONT, DNS หรือวงจรอินเทอร์เน็ตคนละส่วนกัน

สรุปก่อนเริ่ม

ผู้ใช้มักเรียกทุกอาการว่าเน็ตช้า แต่ Wi‑Fi คือการเชื่อมต่อจากอุปกรณ์ไปยัง Router ส่วนอินเทอร์เน็ตคือเส้นทางจาก Router ออกไปยังผู้ให้บริการ

1. ทดสอบใกล้ Router และผ่านสาย

ปิด VPN และงานดาวน์โหลดก่อน วัดความเร็วใกล้ Access Point จากนั้นทดสอบเครื่องเดิมผ่าน LAN หาก LAN ปกติแต่ Wi‑Fi ช้า ปัญหาอยู่ฝั่งไร้สายมากกว่า WAN

2. Ping สองจุด

Ping Default Gateway เพื่อดูเครือข่ายภายใน แล้ว Ping ปลายทางภายนอก เช่น DNS สาธารณะ หาก Gateway มี Latency หรือ Packet loss สูง ให้แก้ Wi‑Fi/LAN ก่อน หาก Gateway ปกติแต่ภายนอกผิดปกติ จึงตรวจ WAN หรือ ISP

3. ปัจจัยของ Wi‑Fi

  • 2.4 GHz ไปไกลแต่แออัดและช้ากว่า
  • 5 GHz เร็วกว่าแต่ทะลุกำแพงน้อยกว่า
  • ช่องสัญญาณซ้อน ตำแหน่ง AP ต่ำหรือถูกบัง
  • อุปกรณ์เก่าและจำนวน Client มากเกินความสามารถ

4. เก็บหลักฐานก่อนแจ้ง ISP

บันทึกเวลา ผล Speed Test ผ่านสาย ค่า Ping/Packet loss สถานะไฟ ONT และอุปกรณ์ที่ได้รับผลกระทบ ข้อมูลนี้ช่วยให้แยกเหตุขัดข้องเป็นช่วงเวลาและลดการวนแก้ซ้ำ
